---
title: Getting started
description: Install Odyssey Desktop, connect your first device, and get it ready to train.
sidebar:
  order: 1
---
1. Download Odyssey Desktop for your computer from the [downloads page](/downloads/), and install it.
2. Open Odyssey Desktop and connect your device: plug it in with USB, or pair it on the **Pairing** page.
3. Calibrate your screen on the **Calibrate** page, following the steps there.
4. Zero your device: on the **Home** page, choose **Zero**, aim at the target in the center of the screen, then save the zero.

When a firmware update is available for a connected device, Odyssey Desktop offers it. Install it when it does.
