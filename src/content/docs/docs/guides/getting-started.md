---
title: Getting started
description: Install Odyssey Desktop and connect your first device.
sidebar:
  order: 1
---
1. Download Odyssey Desktop for your computer from the [downloads page](/downloads).
2. Run the installer and open Odyssey Desktop.
3. Connect your Odyssey device and follow the setup steps in the app.

The app checks for firmware updates for connected devices. Install them when it
offers them.
